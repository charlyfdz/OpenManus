# Prueba local de OpenManus + Ollama

## Objetivo

Evaluar si OpenManus puede convertir una solicitud breve en un entregable local
útil usando únicamente el modelo `llama3.2:1b` ejecutado por Ollama.

## Alcance inicial

- No usar APIs de OpenAI o Anthropic.
- No usar Daytona ni navegación web.
- Generar un pequeño entregable textual sobre una idea ficticia de homelab.
- Revisar calidad, seguimiento de instrucciones y uso de herramientas locales.

Los resultados de la ejecución se conservarán en la carpeta `workspace` de
OpenManus, salvo que la prueba indique explícitamente otro destino.
